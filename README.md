# 🏰 Sand Castle Maker - Análisis Estratégico y Modelo de Negocios

Bienvenido al repositorio que aloja el análisis estratégico formal y la presentación interactiva del proyecto **Sand Castle Maker**.

## 🚀 Sobre este repositorio

Este proyecto contiene el estudio profundo sobre la viabilidad, estrategia y presupuestación del juego indie "Sand Castle Maker". Ha sido desarrollado aplicando conceptos de economía de plataformas, emprendedurismo, y evaluación financiera.

La documentación se presenta en dos formatos:
1. **Presentación Interactiva:** Diapositivas dinámicas diseñadas para la defensa oral del proyecto, con transiciones horizontales intuitivas.
2. **Documento Formal Extendido:** Un informe corporativo y académico exhaustivo, listo para ser exportado a PDF, que justifica cada decisión del negocio (desde el macroambiente PESTEL hasta los indicadores financieros VAN y TIR).

## 🛠️ Tecnologías y Estructura

El repositorio está construido exclusivamente con tecnologías web estáticas (Vanilla), asegurando un rendimiento ultrarrápido y compatibilidad universal:
- **HTML5:** Estructuración semántica de las diapositivas y el informe.
- **CSS3 (Vanilla):** Estilos modernos (Glassmorphism, gradientes, modo oscuro/claro) sin dependencias externas, asegurando un diseño "premium" y fluido.
- **JavaScript (ES6):** Manejo de eventos (scroll, teclado, toques táctiles) para la navegación interactiva de la presentación.

## 📚 Contenidos del Análisis

El informe abarca los siguientes ejes fundamentales:
* **Identidad Institucional:** Misión, Visión y valores (Emprendedurismo B2C).
* **Análisis de Contexto (PESTEL):** Auditoría externa (Oportunidades y Amenazas).
* **Segmentación:** Identificación del mercado potencial y target objetivo.
* **Modelo Estratégico de Porter:** Estrategia competitiva de diferenciación.
* **Estrategia Comercial (Las 4 "P"):** TICs aplicadas al marketing digital (ASO, Freemium).
* **Agenda Estratégica:** Programación de hitos tácticos a 6 meses.
* **Finanzas y Presupuestación:** Cálculo de Costo Estándar ($1.30), Inversión Inicial ($25 USD), TIR y VAN.
* **Métricas de Gestión (KPIs):** Balanced Scorecard y Net Promoter Score (NPS).
